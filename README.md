Заказ принят, держитесь

Заказ принят, держитесь — консольная игра на Java.

Ты — курьер, которому предстоит доставить заказ через опасный район, полный вражеских патрулей и гвардейцев.





## Особенности игры

- 5 уровней сложности.
- Игровое поле от 5×5 до 20×20.
- Математические задания при встрече с противниками.
- Ограниченное количество жизней.
- Два типа противников.





!!! ## Как запустить игру

Потребуется установленная Java JDK.

Открой терминал в папке `src` и выполни:

bash

javac -encoding UTF-8 Main.java Person.java Monster.java BigMonster.java

java Main






## Цель игры

Доберись до точки доставки, сохранив как можно больше жизней.





**Удачной доставки!**
